Circuit schematics

The local points in circuits.json are projected from the LineString features in
Tomislav Bacinger's f1-circuits dataset. The 2025 venue list identifies each
circuit. The coordinates use longitude scaled by the cosine of mean latitude,
north up, translated and uniformly scaled to a 180 by 110 view box. Each venue
has an independent display scale. The source supplies illustrative outlines.
The telemetry API supplies sector-anchored distance but no geographic samples,
so the schematics carry no measured car positions or elevation profiles.
