# Data

| Directory | Contents | Git |
| --- | --- | --- |
| `raw/` | Downloaded or exported source data (OpenF1 JSON, F1DB CSV) | Ignored, except `.gitkeep` |
| `samples/` | Small example datasets used for tests and documentation | Committed |

`raw/` can grow large, so only placeholders are tracked. Keep anything you want
to share small enough to review by hand and put it in `samples/`.
